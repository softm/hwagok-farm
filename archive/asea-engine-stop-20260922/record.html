관리기 엔진정지

공통 5단계를 순서대로 조작한 다음 수동시동형 또는 전기시동형에 맞는 정지 방법으로 마무리합니다.

한눈에 보는 정지 순서

주 클러치 끊김 → 로타리 클러치 끊김 → 조속 저속 → 주행 중립 → 갈이 중립 → 형식별 스위치 정지

순서조작적용
1주 클러치 레버 → 끊김공통
2로타리 클러치 레버 → 끊김공통
3조속레버 → 저속공통
4주행변속레버 → 중립공통
5갈이변속레버 → 중립공통
6수동시동형 정지스위치 → 정지수동시동형
7전기시동형 키스위치 → 정지(OFF)전기시동형

6A와 6B는 연속 단계가 아니라 장비의 시동 형식에 맞는 하나의 방법을 선택합니다.

교육 화면 7장

마지막 확인

  • 주 클러치와 로타리 클러치: 끊김
  • 조속레버: 저속
  • 주행변속·갈이변속: 중립
  • 해당 형식 스위치: 정지 / OFF
  • 엔진과 로터리 날이 완전히 멈춘 뒤 접근
