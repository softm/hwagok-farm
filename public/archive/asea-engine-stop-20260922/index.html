2. 로타리 클러치 레버 → 끊김

사진 2 · 로타리 클러치 레버를 ‘끊김’으로 조작하는 장면.

4. 주행변속레버 → 중립

5. 갈이변속레버 → 중립

6단계 · 시동 형식에 따라 엔진 정지


공통 1~5단계를 마친 뒤, 아래에서 해당 형식의 방법으로 마무리합니다.

6A. 수동시동형 — 정지스위치 → 정지


공통 1~5단계를 마친 뒤, 정지스위치를 ‘정지’ 위치로 옮깁니다.

사진 6 · 수동시동형의 정지스위치를 ‘정지’로 조작하는 장면.

6B. 전기시동형 — 키스위치 → 정지(OFF)


공통 1~5단계를 마친 뒤, 키스위치를 ‘정지(OFF)’ 위치로 돌립니다.

사진 7 · 전기시동형의 키스위치를 ‘정지(OFF)’로 조작하는 장면.

마지막 확인


• 주 클러치와 로타리 클러치는 모두 끊김인지 확인합니다.

• 조속레버는 저속, 주행변속레버와 갈이변속레버는 모두 중립인지 확인합니다.

• 해당 형식의 스위치를 정지 / 정지(OFF)로 조작했는지 확인합니다.


> 저속·중립 설정과 엔진 정지 조작은 구분합니다. 정지 조작 뒤 엔진과 로터리 날이 완전히 멈췄는지 확인하고 접근하세요.
