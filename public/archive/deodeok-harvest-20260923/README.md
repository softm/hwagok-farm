# 화곡농장 더덕 수확·씨앗 채취 아카이브

record.html 또는 index.html을 열면 전체 자료를 볼 수 있습니다.

| 경로 | 내용 |
|---|---|
| record.md / record.html | 재정리한 문서 |
| images/ | JPG 원본 7장 |
| videos/ | HEVC MP4 원본 3개 |
| playback/ | 웹 재생용 H.264/AAC MP4 3개 |
| posters/ | 영상에서 추출한 대표 프레임 3장 |
| record.json | 시각·캡션·원본 체크섬 등 구조화 기록 |
| checksums.sha256 | 패키지 파일 SHA-256 목록 |
| source-documents/ | 초기 정리 문서 보존본 |

사진·영상 원본은 변경하지 않았습니다. 이 패키지의 생성은 GitHub 공개 배포 완료를 뜻하지 않습니다.
