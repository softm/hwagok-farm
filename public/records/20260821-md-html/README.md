# 농막·하우스 CCTV 인터넷 연결 정리

**기준일:** 2026-08-21  
**대상:** 농막, 하우스, 냉동고/컨트롤박스 확인용 CCTV  
**핵심 목적:** 유선 인터넷 설치가 어려운 환경에서 핸드폰 핫스팟·데이터함께쓰기·Wi‑Fi 브릿지·CCTV를 이용해 원격 확인 체계를 구성한다.

---

## 1. 현재 문제

| 구분 | 내용 |
|---|---|
| 농막 | CCTV는 설치되어 있으나 인터넷이 없어 실시간 확인 불가 |
| 하우스 | 냉동고 전원 차단 사고 발생, 식재료 손상 |
| 필요 기능 | 냉동고/컨트롤박스 온도 확인, 출입 확인, 원격 보기 |
| 인터넷 조건 | 유선 인터넷 설치는 현재 불가능한 것으로 판단 |

---

## 2. 현실적인 인터넷 구성

가장 현실적인 1차 구성은 다음과 같다.

```text
SKT 데이터함께쓰기 유심
        ↓
남는 핸드폰
        ↓ 핫스팟 Wi‑Fi
CCTV / Wi‑Fi 브릿지 / Extender
```

| 방식 | 판단 |
|---|---|
| 유선 인터넷 | 현재 설치 어려움 |
| 남는 핸드폰 핫스팟 | 가장 현실적인 임시 구성 |
| LTE/5G 라우터 | 장기 운영용으로 권장 |
| 저가 USB LTE 동글 | 테스트 가능하나 상시 운영 비추천 |
| 스타링크 | 통신 신호가 매우 약할 때 예비안 |

---

## 3. 랜선 전용 CCTV 연결 구성

랜선만 연결되는 CCTV는 핸드폰 핫스팟에 직접 붙을 수 없으므로, 중간에 Wi‑Fi를 유선 LAN으로 바꿔주는 장비가 필요하다.

```text
데이터함께쓰기 유심 들어간 핸드폰
        ↓
핸드폰 핫스팟 Wi‑Fi
        ↓
ipTIME Extender N3
        ↓
랜선
        ↓
랜선 전용 CCTV / DVR / NVR
```

| 장비 | 역할 |
|---|---|
| 남는 핸드폰 | 데이터함께쓰기 유심 장착, 핫스팟 제공 |
| ipTIME Extender N3 | 핫스팟 Wi‑Fi를 받아 LAN 포트로 변환 |
| 랜선 | Extender N3와 CCTV 연결 |
| CCTV 전원 어댑터 | CCTV 전원 공급 |
| UPS | 라우터/핫스팟/브릿지 장비 정전 대비 |

### 설정 순서

1. 남는 핸드폰에서 핫스팟을 켠다.
2. 핫스팟 이름은 영문/숫자로 단순하게 설정한다. 예: `farmwifi`
3. ipTIME Extender N3를 초기화한다.
4. Extender N3를 핫스팟 Wi‑Fi에 연결한다.
5. N3의 LAN 포트와 CCTV를 랜선으로 연결한다.
6. CCTV 전원을 재부팅한다.
7. CCTV 앱 또는 관리 프로그램에서 온라인 여부를 확인한다.

---

## 4. DDNS와 원격보기 주의사항

핸드폰 핫스팟은 통신사 NAT 뒤에 있기 때문에 DDNS/포트포워딩 직접 접속은 거의 어렵다.

| 목적 | 가능 여부 |
|---|---|
| CCTV에 인터넷 연결 | 가능 |
| 같은 현장에서 영상 확인 | 가능 |
| 제조사 앱/P2P 원격보기 | 가능성 높음 |
| DDNS/포트포워딩 직접 접속 | 어려움 |
| 장기 안정 운영 | 핸드폰 핫스팟보다 LTE 라우터가 유리 |

가능성이 높은 방식:

```text
CCTV → 인터넷 접속 → 제조사 서버/P2P → 휴대폰 앱에서 보기
```

어려운 방식:

```text
휴대폰 앱 → DDNS 주소 → 공유기 포트포워딩 → CCTV 직접 접속
```

## 5. SKT 5G 유심과 데이터함께쓰기

사진의 유심은 **SKT 5G NANO USIM CARD**로 확인된다.  
5G 유심이지만, LTE 장비에 꽂으면 LTE로 동작할 수 있다.

| 구분 | 판단 |
|---|---|
| 유심 종류 | SKT 5G 나노 유심 |
| 5G 사용 여부 | 단말기와 요금제, 신호에 따라 결정 |
| LTE 장비 사용 | LTE로 접속 가능성 있음 |
| 라우터 사용 | 단말 등록/요금제 제한 확인 필요 |

---

## 6. 저가 USB LTE 동글 판단

Temu 등에서 판매되는 4G LTE USB Wi‑Fi 동글은 테스트용으로는 가능하지만 장기 운영용으로는 신뢰성이 낮다.

| 항목 | 판단 |
|---|---|
| 5G 사용 | 불가, LTE만 가능 |
| SKT LTE 밴드 | 일부 호환 가능성 있음 |
| 데이터함께쓰기 유심 | 정책/단말 제한 가능 |
| CCTV 상시 인터넷 | 불안정 가능 |
| 추천도 | 낮음~보통 |

주의할 점:

- APN 수동 설정 가능 여부
- 전원 재공급 후 자동 재접속 여부
- 발열
- Wi‑Fi 출력
- 장시간 안정성
- CCTV가 정상 접속되는지

## 9. SD카드 정리

Tapo C320WS는 microSD 저장을 지원하며, 일반 큰 SD카드는 사용할 수 없다.

| 구분 | 사용 가능 |
|---|---:|
| 일반 SD카드 | ❌ |
| microSD | ✅ |
| microSDXC 128GB/256GB/512GB | ✅ |
| 어댑터에 꽂은 큰 SD카드 | ❌ |

### 용량 판단

| 용량 | 움직임 거의 없음 | 상시 녹화 |
|---:|---:|---:|
| 32GB | 1~3주 | 약 1~2일 |
| 64GB | 2~6주 | 약 2~4일 |
| 128GB | 1~3개월 | 약 4~7일 |

나무가 화면에 많이 보이면 바람에 나뭇잎이 흔들려 움직임 감지가 계속 발생할 수 있다.  
감지 구역 설정과 사람 감지 기능을 이용해 나무 영역을 제외하는 것이 좋다.

## 10. 최종 구성안

### 임시/현실 구성

```text
SKT 데이터함께쓰기 유심
        ↓
남는 핸드폰 핫스팟
        ↓
Tapo CCTV 또는 ipTIME Extender N3
        ↓
CCTV 원격 확인
```

### 안정형 구성

```text
SKT/LTE 데이터 회선
        ↓
LTE 라우터
        ↓
CCTV + 온도센서 + 전원센서
        ↓
UPS로 라우터 전원 유지
```

---

## 결론

현재 가장 현실적인 방법은 **남는 핸드폰 핫스팟 + CCTV 연결**이다.  
랜선 전용 CCTV는 **ipTIME Extender N3**를 이용해 핫스팟 Wi‑Fi를 LAN으로 변환하면 된다.  
장기적으로는 **LTE 라우터 + UPS + 온도센서** 구성으로 넘어가는 것이 안정적이다.
