GLOBAL DEPLOYMENT RULE

앞으로 “웹사이트 배포”는
이 구조로 누적합니다.

  1. 01
    메인에서 프로젝트 선택

    모든 프로젝트는 이 중앙 허브의 메뉴에 등록합니다.

  2. 02
    프로젝트 안에 채팅 페이지 등록

    새로운 대화에서 배포한 사이트는 해당 프로젝트 카드 아래에 추가합니다.

  3. 03
    자료는 페이지 안에서 레이어로 확인

    이미지·영상·PDF·문서는 가능한 경우 팝업으로 크게 볼 수 있게 구성합니다.

  4. 04
    기존 주소도 중앙에서 연결

    이미 따로 배포된 사이트를 없애지 않고 중앙 메뉴에서 찾아갈 수 있게 유지합니다.
