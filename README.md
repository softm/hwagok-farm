## 모든 정리·재정리·배포 작업의 필수 기준

공유 기준: [전역 아카이브 배포 규칙](https://github.com/softm/softm.github.io/blob/main/projects/README.md)

2026-09-30 사용자 재확정: **사진 및 미디어는 반드시 포함해서 정리한다.** 별도로 "사진 포함"이나 "영상 포함"이라고 말하지 않아도 적용한다.

- 해당 채팅의 사진·영상·음성·녹취·문서 및 압축파일 속 관련 첨부 원본을 전수 확인한다.
- 상세 본문을 축약본으로 대체하지 않는다. 원본 파일명·바이트·해시를 보존하고, 변환본은 원본과 별도로 둔다.
- 사진은 본문·갤러리에서 실제 표시하고, 영상·음성은 실제 재생 및 원본 다운로드를 제공한다.
- HTML·MD·ZIP의 참조와 원본 개수를 대조한다. ZIP에만 넣고 웹에서 빠뜨리거나 파일명 목록만 남기지 않는다.
- 배포는 첨부 원본, ZIP, GitHub 저장소, 실제 운영 파일의 내용·개수·해시 및 표시·재생을 각각 확인한다. HTTP 200, 파일 객체 생성, 커밋 또는 CI 성공만으로 완료라고 보고하지 않는다.
- 원본 누락·전송 실패·재생 미검증은 파일명·개수·단계·사유와 함께 알리고 완료 처리하지 않는다.
- 기존 저장소·프로젝트 홈·최상위 Projects 연결을 유지한다. 민감 원본은 공개하지 않으며 무관한 외부 서비스로 우회 업로드하지 않는다.

위 링크는 프로젝트 간 공유 규칙이다. 링크 추가 자체가 누락 미디어 복구나 다른 프로젝트의 배포 완료를 뜻하지 않는다.
