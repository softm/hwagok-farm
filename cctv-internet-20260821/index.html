인터넷 확보 방식

임시안

데이터함께쓰기 유심 + 남는 핸드폰 핫스팟.

랜선 CCTV

핫스팟 → ipTIME Extender N3 → LAN → CCTV.

장기 운영안

LTE/5G 라우터 + UPS + CCTV.

현장 체크

  • 핫스팟 이름은 영문·숫자로 단순하게 설정
  • CCTV·핫스팟폰·Extender를 상시 전원 연결
  • 제조사 앱/P2P/Cloud 원격보기 지원 확인
  • 전원 복구 후 자동 재접속 여부 확인
