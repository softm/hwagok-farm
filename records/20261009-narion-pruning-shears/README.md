# 20261009 나리온 40mm 전지가위 구매 검토

**프로젝트:** 화곡농장 / 농기계 · 구매 검토  
**기록일:** 2026-10-09 (상품 선택 화면 기준)  
**작성일:** 2026-10-10  
**상태:** **2026-10-10 주문완료 및 신용카드 결제 완료 (159,000원)**

## 주문완료 확인 (2026-10-10)

첨부 주문완료 화면에서 **나리온 40mm 전지가위 베어툴 1개**, **159,000원 신용카드 결제 완료**, **무료배송**, **적립 예정 3,600원**을 확인했다. 배터리는 미포함이고 기존 컷쏘 배터리 2개를 재사용할 계획이다. 배송 완료 여부와 실물 B형 배터리 규격은 아직 미확인이다.

**개인정보 보호:** 주문완료 화면에는 주문번호·수령인·이메일·주소·연락처가 포함되어 원본은 로컬 사용자 보관용 ZIP에만 저장한다. 공개 웹페이지에는 [비식별 요약 이미지](https://raw.githubusercontent.com/softm/hwagok-farm/main/public/records/20261009-narion-pruning-shears/images/order-summary-public.svg)만 게시한다. 상품 선택 화면 원본 2개는 웹 게시 미완료로 별도 검증한다.

## 핵심 결론

나리온 40mm 전지가위 베어툴 선택가격은 **159,000원**이다. 배터리 미포함 구성이다. 과거 나리온 소형 컷쏘를 구매하면서 배터리 2개를 보유한 사용자는 **추가 배터리를 주문하지 않으려 한다**. 기존 실물 배터리가 21V B형인지 라벨·결합부 확인이 남아 있다.

함께 표시된 **체인오일 500ml 9,900원은 구매에서 제외**한다. 체인톱 체인·가이드바용 오일을 전지가위 전체나 전기접점에 분사하지 않는다. 가위날·회전축 윤활 지점과 윤활유 규격은 제조사 설명서의 지시를 따른다.

## 체인오일과 관리법

1. 전지가위 배터리를 제거한 후 가위날 수액·오염을 닦는다.
2. 제조사 설명서가 허용한 윤활 지점에 적합한 윤활제를 소량 사용한다.
3. 모터·배터리 접점에 체인오일을 분사하거나 확인되지 않은 구멍에 임의 주입하지 않는다.
4. 기존 컷쏘는 왕복톱날 방식이므로 체인톱처럼 체인오일 탱크를 전제로 하지 않는다.

## 대화 진행 경과

1. 전지가위 공식몰 화면에서 40mm 베어툴 선택금액 159,000원을 확인했다.
2. 전지가위와 B형 배터리, 과거 컷쏘 공식몰 링크를 공유했다.
3. 기존 컷쏘 배터리 두 개를 재사용하여 배터리를 추가 구매하지 않기로 했다.
4. 배터리가 실제 B형인지는 실물 증빙이 없어 100% 확정하지 않았다.
5. 체인오일 500ml는 불필요한 추가구매로 판단해 제외했다.
6. 정리·배포 명령에 따라 자료를 아카이브화했다.

## 원본 및 공개판 상태

로컬 ZIP에는 상품 선택 화면 2개와 **개인정보가 포함된 주문완료 증빙 1개**, 원본 PNG 총 3개가 보존된다. 공개 저장소에는 개인정보가 담긴 주문 원본을 게시하지 않는다. 현재 공개 웹의 원본 상품 이미지 2개는 아직 게시되지 않았다.
