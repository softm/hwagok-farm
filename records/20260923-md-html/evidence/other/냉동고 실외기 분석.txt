사진을 보니 **FOX-S1004** 온도조절기입니다.

이 모델은 **온도편차(히스테리시스, Differential)**를 변경할 수 있습니다.

### 설정 방법(일반적인 FOX-S1004)

1. **SET 버튼을 3~5초 길게 누릅니다.**
2. 첫 번째 또는 두 번째 메뉴에서 **`Hy`**, **`di`**, **`dIF`**(모델마다 표시 다름)가 나오면 온도편차입니다.
3. ▲▼ 버튼으로 값을 변경합니다.
4. **SET**을 눌러 저장합니다.

### 추천값

현재는
- 정지: **-15℃**
- 재가동: **-13℃**
- 편차: **2℃**

이라면,

편차를 **3℃**로 하면
- 정지: **-15℃**
- 재가동: **-12℃**

가 되어 콤프레서 기동 횟수가 줄어듭니다.

편차를 **4℃**로 하면
- 정지: **-15℃**
- 재가동: **-11℃**

가 되어 전력 소모와 기동 횟수는 더 줄지만, 내부 온도 변화폭은 커집니다.

**SET 버튼을 5초 정도 눌렀을 때 화면에 어떤 글자가 나오는지** 알려주세요.
예를 들어 `SP`, `Hy`, `di`, `P0` 같은 표시가 나오면 그다음 단계부터 정확하게 안내해 드리겠습니다.
