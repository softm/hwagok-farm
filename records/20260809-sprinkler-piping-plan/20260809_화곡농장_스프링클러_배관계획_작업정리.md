| 급수 시작점 | 지도에 표시한 복수의 수도 위치를 기준으로 구간별 배관 연결 |
| 배관 표현 | 청색 배관과 황색 끝점·연결점을 사용하고, 5m 단위 배관 심벌을 각도별로 제작 |
| 살수 표현 | 스프링클러 중심점과 녹색 원으로 살수 범위를 표시. 직경 5m·10m 기준 이미지 별도 제작 |

| 예각 보완 | 꺾인 예각 구간은 개별 변 외에 시작점과 끝점을 잇는 `TOTAL ~○m` 보완 직선을 표시 |
| 축척 기준 | 원본 도면 작업 기준 공통 축척 약 3.33px/m, 5m·10m·20m 배관 비교 기준 사용 |

### 배치 구역 해석

1. **상단 구역**: 짧고 불규칙한 필지 경계 안에 스프링클러를 격자형으로 배치하고, 상단 수도·주배관에서 분기한다.
2. **동측 세로 구역**: 길고 좁은 밭을 따라 주배관을 세로로 연결하고 스프링클러를 연속 배치한다.
3. **남서측 구역**: 삼각형에 가까운 밭의 긴 변을 따라 배관을 배치하고 내부가 겹쳐 살수되도록 구성한다.
4. **중앙·남동측 미배치 구역**: 경계와 추정 치수는 작성했지만 스프링클러·배관의 최종 위치는 아직 확정하지 않은 영역이 남아 있다.

## 3. 도면 표시 기준

| 표시 | 의미 |
|---|---|
| 주황색 외곽선 | 필지·보완 다각형 경계 |
| 검은색 `~○m` | 위성지도 축척으로 계산한 변 길이 근사값 |
| `TOTAL ~○m` | 예각 양 끝점을 직선으로 연결한 전체 길이 근사값 |
| 청색 굵은 선 | 계획 배관 또는 5m 배관 심벌을 이어 만든 배관 경로 |
| 황색 원 | 배관 끝점·연결점·분기 기준점 |
| 흰색 수도꼭지 | 확인된 급수 위치 |
| 스프링클러 삼각대 | 스프링클러 설치 후보 위치 |
| 녹색 원 | 스프링클러 살수 범위. `D=5m`는 반경 2.5m, `D=10m`는 반경 5m |

## 4. 작업 진행 과정

1. 위성 평면본과 지번 표시본을 기준 이미지로 준비했다.
2. 수도 위치를 표시하고 관수 대상 필지의 가로·세로 길이를 먼저 추정했다.
3. 직사각형만으로 표현되지 않는 누락 영역을 주황색 다각형으로 보완했다.
4. 전체 경계의 각 선분에 공통 축척을 적용해 길이를 표시했다.
5. 예각 구간에는 꺾인 변의 합과 별도로 양 끝점을 잇는 전체길이 보완선을 추가했다.
6. 왼쪽 아래에 지도 축척과 대응하는 5m·10m·20m 배관 기준을 배치했다.
7. 스프링클러 단독, 직경 5m, 직경 10m 살수영역 이미지를 투명 PNG로 제작했다.
8. 5m 배관을 여러 각도로 돌려 쓸 수 있는 심벌과 연결부 심벌을 만들었다.
9. 수도 위치에서 관수 구역으로 이어지는 배관과 스프링클러를 지도에 배치해 현재 종합 계획도를 완성했다.

## 5. 현재 확정된 제작 규칙

- 평면본과 지번본은 같은 좌표·같은 축척·같은 치수 목록을 사용한다.
- 공유 경계는 같은 선을 중복 표기하지 않는다.
- 짧은 변도 임의로 생략하지 않고 가능한 모든 고유 선분에 치수를 표시한다.
- 예각 `TOTAL` 문구는 다른 치수와 겹치지 않게 배치한다.
- 배관 비교 기준은 왼쪽 아래에 5m·10m·20m를 1:2:4 비율로 표시한다.
- 스프링클러 직경 기준은 5m와 10m를 함께 제공한다.
- 최종 도면에서 스프링클러 심벌은 흰색·대형으로 표시해 위성 배경에서 잘 보이게 한다.
- `~` 표시는 측량값이 아닌 지도 기반 추정값임을 뜻한다.

## 6. 시공 전 확인할 사항

- 이 도면은 **관수 계획용 참고도**이며 지적측량 성과도나 시공 확정도면이 아니다.
- 현장에서 수도 위치, 실제 이동 동선, 경사, 작물 열 방향, 장애물과 필지 경계를 다시 확인해야 한다.
- 스프링클러의 실제 살수 직경은 수압, 유량, 노즐, 바람에 따라 달라질 수 있다.
- 여러 스프링클러를 동시에 가동하려면 수도의 유량·압력을 측정한 뒤 구역별 밸브 운전 여부를 결정해야 한다.
- 배관 구경·재질과 실제 연결 규격을 정한 후 5m 배관 수량, 소켓·엘보·T분기·밸브·말단마개 수량을 확정해야 한다.
- 현재 종합본의 배치 심벌은 일부 겹쳐 보이므로 최종 출력본에서는 흰색 대형 심벌과 겹침 방지 표기를 일관되게 적용해야 한다.
