# 공개 기록 사용 안내

압축을 풀고 `index.html`을 브라우저에서 열면 문서와 사진 확대 기능을 오프라인으로 볼 수 있습니다. `record.md`가 마크다운 문서입니다. `images` 폴더를 HTML·MD와 함께 보관해 주세요.

공개 사진에는 번호판 가림 및 EXIF 제거가 적용되어 있습니다. 원본 파일은 포함하지 않았습니다. 사용자 원문·사진 관찰·계산값·미확인 항목을 구분했습니다.

페이지의 프로젝트 이동·ZIP 받기·GitHub 링크는 인터넷 연결이 필요합니다. 인원·면적·비용·점심 및 휴게시간은 제공되지 않았습니다.
