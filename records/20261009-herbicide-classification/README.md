# 2026-10-09 제초제 분류 및 사용 가이드

> 화곡농장 보유 제품 비교. **실제 사용은 제품 라벨 및 농약안전정보시스템의 해당 작물 등록사항을 우선 확인**합니다.

| 제품 | 분류 | 주요 처리 방식 | 주의 |
|---|---|---|---|
| 스톰프 | 선택성 토양처리 제초제 | 잡초 발생 전 | 작물별 등록·파종시기 확인 |
| 케이펜디 | 제품 성분 확인 필요 | 발아 전 토양처리로 알려짐 | 라벨 확인 전 단정 금지 |
| 라쏘 | 선택성 토양처리 제초제 | 잡초 발생 전 | 등록 작물·사용시기 확인 |
| 단골 | 제품 등록사항 확인 필요 | 제품별 확인 | 들깨 사용 가능 여부 별도 확인 |
| 풀앤짱 | 비선택성 경엽처리 | 이미 자란 잡초 | 작물에 닿지 않도록 주의 |
| 푸리타 | 비선택성 경엽처리 | 이미 자란 잡초 | 작물에 닿지 않도록 주의 |

## 분류 기준
- 선택성/비선택성은 작물과 잡초에 대한 상대적 작용을 구분합니다.
- 발아 전 토양처리/생육기 경엽처리는 **처리 시기·방법**에 관한 별도 구분입니다.
- 따라서 선택성 제초제가 모두 발아억제제인 것은 아닙니다.
- 푸리타가 농축되어 있어도 **동일 희석조건의 실제 제초력 우위**를 단정할 수 없습니다.

## 안전
들깨·열무 등 재배 중 작물에 비선택성 제초제 약액이 닿으면 약해가 생길 수 있습니다. 등록되지 않은 작물에는 사용하지 마세요.
